Sarah Johnson, CNA — Portfolio Website
=======================================

Files
- index.html  → page content
- styles.css  → all styling
- script.js   → mobile menu, scroll animations, contact form

How to use
1. Unzip this folder.
2. Double-click index.html to open it in your browser.
3. To publish, upload the whole folder to Netlify, GitHub Pages, Vercel, or any web host.

Customize
- Edit text directly in index.html.
- Change colors in the :root section at the top of styles.css.
- To receive real messages, connect the contact form to a service like Formspree (see the note in script.js).
